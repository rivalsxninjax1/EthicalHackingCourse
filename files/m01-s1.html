What is cybersecurity?

Protecting systems, networks and data from unauthorized access, damage or disruption.

Asset

Anything of value: data, servers, accounts, reputation

Threat

Anyone or anything that can cause harm

Vulnerability

A weakness a threat can use

Risk

Likelihood × impact of a threat using a vulnerability

Ask: "What is the most valuable asset on your phone?" Use answers as examples for each card.

The CIA Triad

  • Confidentiality: only the right people can read it
  • Integrity: data is accurate and unaltered
  • Availability: systems work when needed
Every security control and every attack maps to at least one of these three. Keep returning to this slide all course.

CIA in real attacks

Confidentiality

Data breach

A leaked customer database or a stolen password list

Integrity

Tampering

A defaced website, or a changed bank balance or exam result

Availability

Disruption

DDoS knocks a site offline; ransomware locks every file

Discussion: which one hurts a hospital most?

Types of hackers

White hat

Has permission. Finds and reports weaknesses to improve security. This is us.

Grey hat

No permission, but usually no malicious goal. Still illegal.

Black hat

No permission, harmful intent: theft, fraud, damage.

The difference is not skill. It is permission and intent.

Findings and fixes

Modules 5–13 follow exactly this order.

Mention the Lockheed Martin Cyber Kill Chain as the attacker's view of the same flow. Reporting is the phase that makes us professionals, not criminals.

Types of penetration tests

Type Tester knows Simulates
Black box Nothing An outside attacker
Grey box Some info (a user account, a network map) A user or partner gone bad
White box Everything (source code, architecture) A deep audit

The law

Authorization is the line between a pentester and a criminal.

  • Unauthorized access, data damage and similar computer offences are punishable under Nepal's Electronic Transactions Act, 2063
  • "I was only testing" is not a defence
  • Practise only on your own lab or on platforms that allow it
Teacher: check the current ETA text and any amendments or newer cyber laws before class, and cite specific sections if you want to.

Rules of Engagement (RoE)

A real test starts with a signed document that defines:

Scope

Exactly which systems and IPs are allowed

Timing

When testing may happen

Methods

What is allowed or banned (DoS, social engineering…)

Data handling

How findings and data are stored and protected

Student code of conduct

  • I attack only the lab machines my instructor provides
  • I never test a real website, network or person without written permission
  • I report weaknesses I find; I do not exploit them for gain
  • I protect any data I see during labs

Everyone signs the ethics agreement before Module 4.

Quick check

  • A ransomware attack mainly breaks which part of CIA? → Availability
  • A hacker finds a bug without permission and reports it. Which hat? → Grey
  • Which pentest phase comes right after scanning? → Exploitation
  • What makes a pentest legal? → Written authorization (scope + RoE)

Recap

  • CIA: confidentiality, integrity, availability
  • Hacker types differ by permission and intent
  • Pentest = 5 phases, ending in a report
  • No authorization, no hacking
